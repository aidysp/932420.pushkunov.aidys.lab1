## 📚 Историческая справка и концепция
Страница стилизована под персональный блог историка-реконструктора, занимающегося материальной культурой **Теленгитского улуса (Телеутского княжества) XVII–XVIII веков**. 
Вся текстовая часть, включая описание комплексов вооружения («белых калмыков») и картографии торговых путей, опирается на реальные исторические труды и графические реконструкции доктора исторических наук **Л. П. Боброва**.

## 🚀 Как запустить проект локально

1. Склонируйте репозиторий или скачайте архив с проектом:
   ```bash
   git clone [ссылка_на_ваш_репозиторий]
   ```
2. Перейдите в папку с проектом.
3. Откройте файл `index.html` в любом современном браузере (Google Chrome, Яндекс.Браузер, Mozilla Firefox).
